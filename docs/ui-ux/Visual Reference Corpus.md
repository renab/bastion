# Bastion UI/UX Visual Reference Corpus

This corpus turns the current product decisions into source-audited, deliberately static visual references. It is **not production UI**, does not depict live state, and uses sanitized prototype/sample data only. Generated art illustrates interaction hierarchy and density; the adjoining document is the governing interpretation.

## How to use this corpus

Each domain folder contains a UI concept, source audit, visual-generation brief, and mockup audit in one reference document plus one full-resolution reference image. The reference image is not a screen specification; the product records and named Obsidian design notes remain authoritative.

## Common design contract

- EVE-inspired black glass, restrained nebula, crisp precision borders, dense desktop workspaces, and the Naffin blue/gold palette only for non-semantic styling.
- Semantic success, danger, warning, topology class, and opportunity-grade colors are independent of branding.
- Contextual drawers inspect without breaking work; every drawer offers **Open Source** and **View Full Page**. Breadcrumbs reflect traversal, not the navigation tree.
- Every example is visibly marked **PROTOTYPE - SAMPLE DATA - NOT LIVE**. No private character, asset, wallet, authentication, or operational data appears.
- The product uses compact operational copy, full canonical character names in live implementations, and no motivational or architectural rationale in normal UI.
